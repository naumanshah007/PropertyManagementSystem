# Vendor Demo Script

## Demo Story

Before: an estimator manually reads a 50-page asbestos survey and prepares a quote.

After: TraceQuote AI extracts register items, no-access risks, Class A/Class B details, and creates a reviewed quote draft with evidence behind every line.

## Hero Demo File

Use the provided asbestos survey:

```text
38-Asbestos-Survey-_Rev_0.pdf
```

## Demo Flow

1. Open Dashboard.
2. Click New Quote Workup.
3. Upload `38-Asbestos-Survey-_Rev_0.pdf`.
4. System identifies the document as an asbestos demolition/refurbishment survey.
5. System extracts asbestos register items.
6. System flags no-access power boxes and limited-access chimney/AIB issues where present.
7. System shows Class A/Class B visibility.
8. Estimator reviews the evidence page references.
9. System generates draft quote sections:
   - Site establishment
   - Class B cladding removal
   - Class A AIB/friable material allowance where applicable
   - Power box provisional investigation
   - Waste disposal
   - Encapsulation
   - Assessor/clearance note
   - Access exclusions
   - No-access provisional allowance
10. Estimator edits one rate or quantity.
11. System records the edit in the audit trail.
12. Estimator completes approval checklist.
13. System exports quote draft with assumptions, exclusions, and evidence appendix.

## Vendor-Facing Talk Track

TraceQuote AI is not replacing your estimator. It gives the estimator a governed AI workbench that reads the survey, prepares the first quote draft, shows the evidence behind every line, and learns from every correction.

## Demo Success Criteria

- The product feels like enterprise compliance software, not a chatbot.
- The vendor can see where extracted data came from.
- The estimator can override AI output.
- No-access, provisional, and Class A/Class B risks are visible.
- The quote package looks commercially useful.
